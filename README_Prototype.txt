THE AUDIT SPINE — PORTABLE PRODUCT PROTOTYPE
Version 1.0 | Design review edition | 22 September 2026

Extract all files into one folder and open index.html in a modern browser. Keep app.js, data.js and styles.css beside it. No account, installation, server or network service is required by the prototype. JavaScript must be enabled. The interface uses synthetic data only. Refreshing or Reset clears session changes.

Purpose
Explore four workspaces and 32 screen families across 18 modules. Choose a simulated persona and workspace. Screen navigation, Record details and Rules and lifecycle expose the design. Persona choices demonstrate boundaries; they are not a real authentication or security implementation. Some actions display a preview only. No evidence is uploaded, report issued, source acquired, invoice created or external message sent.

Suggested walkthrough
1. Company owner: inspect Scope and preparation, then Evidence. Simulate intake and observe quarantine before safe admission. A safe file is not automatically relevant.
2. Lead assessor: review the separate evidence uses and interview context. Confirming recorded wording does not establish compliance. Compare the limited second use and private/shared material.
3. Qualified TAS expert: authorise the exact catalogue subject. Publication remains blocked by distribution rights. Switch to Rights steward and renew the simulated rights: eligible software execution activates once without a second human release request.
4. Scope specialist: review the local change pack. Company owner can then adopt the preparation baseline. Lead assessor separately amends the engagement. The historical report keeps its original release and evidence version.
5. Lead assessor: inspect the disputed finding, assemble the synthetic report candidate and simulate issue. Repeating issue does not create a duplicate receipt. Editing relevant fields requires renewed candidate handling.
6. Alex: inspect the limited ENG-A context. Company owner can simulate revocation; Alex's subsequent view is unavailable. Service operator can inspect jobs but cannot approve catalogue content.
7. Explore collection partial capture and retry, optional cited drafting, commercial sponsorship and exit previews. A complete capture of the requested set is not proof of a complete estate; sponsorship never grants evidence access.

Verification boundary
Fourteen targeted JavaScript VM checks passed for template generation, linked screen IDs and selected state transitions. They use a minimal DOM stub, not a browser. Actual browser layout, click wiring, keyboard navigation, focus, responsive layout and assistive technology have NOT been verified. A browser download was cancelled at the network approval boundary; no alternate download was attempted. This is an explicitly unqualified review prototype, not an implementation or accessibility certification.

The document figures are illustrative interface concepts generated from the same screen definitions; they are not browser screenshots. Native professional methods, report templates, rights, operating policies and production controls require independent qualification.
